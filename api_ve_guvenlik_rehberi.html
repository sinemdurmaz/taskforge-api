API Router, JWT & Rol Güvenliği (RBAC)

Dış dünyaya açılan FastAPI kapılarımız: Token çözümleme, yetkilendirme ve Swagger UI.

🛡️ 1. Rol Tabanlı Yetkilendirme (RBAC)

Bir kullanıcının rolüne göre hangi kapılardan geçebileceğini api/deps.py içindeki require_role bağımlılığı belirler:

Admin & Manager

Yeni projeler açabilir (POST /projects), kullanıcıları yönetebilir ve sprintler planlayabilir.

Developer

Kendisine atanan görevleri görebilir, durumunu TODO -> IN_PROGRESS -> IN_REVIEW yapabilir, acil görevleri kuyruktan çekebilir.

🚀 2. Yayındaki API Endpoint'leri

Tarayıcınızda http://127.0.0.1:8000/docs adresine girdiğinizde etkileşimli olarak test edebileceğiniz kapılar:

POST /api/v1/auth/register • Yeni kullanıcı kaydı
POST /api/v1/auth/login • Giriş yapıp JWT Token alma
GET /api/v1/auth/me • Oturum açmış kullanıcı profili
POST /api/v1/projects • Proje oluşturma (Admin/Manager)
POST /api/v1/tasks • Yeni görev oluşturma
GET /api/v1/tasks/project/{id}/urgent • Min-Heap: En acil görevler
GET /api/v1/tasks/project/{id}/by-tags • Hash Set: Etiket araması
PATCH /api/v1/tasks/{id}/status • State Machine: Durum güncelleme
